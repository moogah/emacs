A submodule of the =emacs-agent= module, loaded by =emacs-agent.org= through =jf/load-module=.

* Lexical Binding

The lexical-binding mode line MUST be on line 1 of the tangled file, so this first block uses
=:comments no= to keep org structure comments from being inserted ahead of it.

#+begin_src emacs-lisp :comments no
;;; presets.el --- emacs-agent-read / emacs-agent-write presets -*- lexical-binding: t; -*-
#+end_src

* The agent presets

=emacs-agent-read= and =emacs-agent-write= will be registered here as gptel presets by
=jf/agent-presets-register= through =jf/gptel-preset-register=, from =with-eval-after-load 'gptel=,
each =:tools= a list of tool names (design.md seam/agent-presets).

Until a later task of the change fills it, this file is a stub: it loads cleanly and requires nothing.

* Module Initialization

#+begin_src emacs-lisp
(provide 'emacs-agent-presets)
;;; presets.el ends here
#+end_src
