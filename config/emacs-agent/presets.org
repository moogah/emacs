A submodule of the =emacs-agent= module, loaded by =emacs-agent.org= through =jf/load-module=.

Two gptel presets are the allowlists of the agent surface (design.md D11, D25; seam/agent-presets):

- =emacs-agent-read= — the tools an agent may run at the =call= tier;
- =emacs-agent-write= — the tools that, with the read ones, it may run at =call-write=.

They are ordinary gptel presets: registered through =jf/gptel-preset-register=, so they live in
=gptel--known-presets= and appear in gptel's preset menu.  Each =:tools= is a list of tool *names*,
not tool structs, so a preset may name a tool that registers later (or never): the name is resolved
against gptel's registry only when the tool is called (seam/registry-access).

This file holds the vocabulary of the surface too: which presets a tier opens
(=jf/agent--tier-presets=) and which tier the manifest gives a tool (=jf/agent-tool-tier=).

* Lexical Binding

The lexical-binding mode line MUST be on line 1 of the tangled file, so this first block uses
=:comments no= to keep org structure comments from being inserted ahead of it.

* Dependencies

Nothing is required at load: gptel and the preset registration module are reached through
=with-eval-after-load= (see [[*Registration][Registration]]), and the readers below answer nil when gptel is absent.

#+begin_src emacs-lisp
(declare-function gptel-get-preset "gptel" (name))
(declare-function jf/gptel-preset-register "gptel-preset-registration" (name &rest config))
(declare-function jf/gptel-scope-profile--resolve-tool-names "scope-profiles" (tools-spec))
#+end_src

* The initial tool lists

The read preset holds org-graph's two read tools, the org-roam read tools and the four introspection
tools (D26: =emacs_*=, registered by =introspection-tools.org=).  The write preset holds org-graph's
write tool and the two workspace layout tools (D17).  No scope-wrapped, interactive or
control-helper tool belongs in either.

#+begin_src emacs-lisp
(defconst jf/agent-presets--read-tools
  '("org_graph_query" "org_graph_typed_edges"
    "search_roam_nodes" "list_roam_nodes" "read_roam_node"
    "get_roam_node_metadata" "query_roam_backlinks"
    "emacs_describe_symbol" "emacs_find_definition"
    "emacs_variable_value" "emacs_apropos")
  "Tool names of the initial `emacs-agent-read' preset.")

(defconst jf/agent-presets--write-tools
  '("org_graph_write_node" "workspace_add_layout" "workspace_remove_layout")
  "Tool names of the initial `emacs-agent-write' preset.")
#+end_src

* Registering the presets

#+begin_src emacs-lisp
(defun jf/agent-presets-register ()
  "Register the `emacs-agent-read' and `emacs-agent-write' gptel presets.
Each preset's :tools is a list of tool names.  Idempotent: registering
again replaces both presets with the initial lists."
  (jf/gptel-preset-register
   'emacs-agent-read
   :description "Tools an external agent may run read-only (emacs-agent call tier)."
   :tools (copy-sequence jf/agent-presets--read-tools))
  (jf/gptel-preset-register
   'emacs-agent-write
   :description "Tools an external agent may run that change state (emacs-agent call-write tier)."
   :tools (copy-sequence jf/agent-presets--write-tools)))
#+end_src

* Reading a preset's tools

=jf/agent-preset-tool-names= is the only reader of the agent presets' =:tools=.  It reads the preset
from gptel's preset table each time, so a change to a preset shows at the next call.

#+begin_src emacs-lisp
(defun jf/agent-preset-tool-names (preset)
  "Return the tool names of the gptel preset PRESET (a symbol), or nil.
The preset's :tools is resolved to name strings with
`jf/gptel-scope-profile--resolve-tool-names'.  Nil when gptel is not
loaded or PRESET is not registered."
  (let ((spec (and (fboundp 'gptel-get-preset) (gptel-get-preset preset))))
    (and spec
         (jf/gptel-scope-profile--resolve-tool-names (plist-get spec :tools)))))
#+end_src

* The tier vocabulary

=jf/agent--tier-presets= is the one mapping from a dispatcher tier to the presets it opens.
=jf/agent-tool-tier= is the manifest's: the tier an agent needs to run a tool.

#+begin_src emacs-lisp
(defun jf/agent--tier-presets (tier)
  "Return the agent presets the tier TIER (a string) opens.
\"call\" opens `emacs-agent-read'; \"call-write\" opens it and
`emacs-agent-write'.  Any other TIER opens nothing: nil."
  (pcase tier
    ("call" (list 'emacs-agent-read))
    ("call-write" (list 'emacs-agent-read 'emacs-agent-write))))

(defun jf/agent-tool-tier (name)
  "Return the manifest tier of the tool NAME: \"read\", \"write\" or nil.
\"read\" when NAME is in `emacs-agent-read', \"write\" when it is only in
`emacs-agent-write', nil when it is in neither."
  (cond ((member name (jf/agent-preset-tool-names 'emacs-agent-read)) "read")
        ((member name (jf/agent-preset-tool-names 'emacs-agent-write)) "write")))
#+end_src

* Registration

The presets register once both gptel and the preset registration module
(=config/gptel/presets/registration.org=, feature =gptel-preset-registration=) are loaded, whichever
comes last; in the full configuration both are loaded before this module, so registration runs at
load.

#+begin_src emacs-lisp
(with-eval-after-load 'gptel
  (with-eval-after-load 'gptel-preset-registration
    (jf/agent-presets-register)))
#+end_src
