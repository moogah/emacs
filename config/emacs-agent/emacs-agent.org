The agent-facing surface of this configuration: a dispatcher that runs preset-allowlisted gptel
tools on behalf of an external agent driving Emacs through =emacsclient= (=bin/emacs-agent=), the
=emacs-agent-read= / =emacs-agent-write= presets that bound it, the manifest an agent reads, a set
of read-only introspection tools, the live-session action log, and the helpers a target Emacs
needs for observation and control.

This file is the top-level loader for the =emacs-agent= module (feature =emacs-agent=).  Behavior
lives in the submodules under =config/emacs-agent/=, loaded from the [[#submodules][Submodules]]
section.  The module is the =jf/enabled-modules= entry ="emacs-agent/emacs-agent"=, after
="org-graph/org-graph"= (design.md D8, D20; seam/module-load).

* Lexical Binding

The lexical-binding mode line MUST be on line 1 of the tangled file, so this first block uses
=:comments no= to keep org structure comments from being inserted ahead of it.

#+begin_src emacs-lisp :comments no
;;; emacs-agent.el --- Agent-facing dispatcher, presets and target support -*- lexical-binding: t; -*-
#+end_src

* Submodules
:PROPERTIES:
:CUSTOM_ID: submodules
:END:

Each submodule's basename differs from the feature it =provide='s (=dispatcher.el= →
=emacs-agent-dispatcher=, …), so each is loaded by path through =jf/load-module=, in this order.
None of them requires gptel at load: the presets and the introspection tools register from
=with-eval-after-load 'gptel=, and =target-support= needs only built-in libraries so that a =-Q=
target can load it by path on its own.

#+begin_src emacs-lisp
(jf/load-module (expand-file-name "config/emacs-agent/dispatcher.el"          jf/emacs-dir))
(jf/load-module (expand-file-name "config/emacs-agent/presets.el"             jf/emacs-dir))
(jf/load-module (expand-file-name "config/emacs-agent/manifest.el"            jf/emacs-dir))
(jf/load-module (expand-file-name "config/emacs-agent/introspection-tools.el" jf/emacs-dir))
(jf/load-module (expand-file-name "config/emacs-agent/action-log.el"          jf/emacs-dir))
(jf/load-module (expand-file-name "config/emacs-agent/target-support.el"      jf/emacs-dir))
#+end_src
