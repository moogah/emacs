* The dispatcher

=jf/agent-call TIER TOOL-NAME JSON= will live here: it refuses a tool outside the tier's preset before
decoding anything, reads the tool through =jf/agent--registry-lookup=, passes the JSON arguments
exactly as =gptel--handle-tool-use= does, and refuses asynchronous tools while D24 holds
(design.md seam/dispatcher-args, seam/tier-enforcement, seam/registry-access, seam/async-protocol).

Until a later task of the change fills it, this file is a stub: it loads cleanly and requires nothing.
