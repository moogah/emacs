A submodule of the =emacs-agent= module, loaded by =emacs-agent.org= through =jf/load-module=.

* Lexical Binding

The lexical-binding mode line MUST be on line 1 of the tangled file, so this first block uses
=:comments no= to keep org structure comments from being inserted ahead of it.

#+begin_src emacs-lisp :comments no
;;; introspection-tools.el --- Read-only Emacs introspection gptel tools -*- lexical-binding: t; -*-
#+end_src

* The introspection tools

Four synchronous read-only gptel tools in category ="introspection"= (=emacs_describe_symbol=
and its siblings) will be registered here by =jf/agent-introspection-tools-register= from
=with-eval-after-load 'gptel= (design.md seam/introspection-tools).

Until a later task of the change fills it, this file is a stub: it loads cleanly and requires nothing.

* Module Initialization

#+begin_src emacs-lisp
(provide 'emacs-agent-introspection-tools)
;;; introspection-tools.el ends here
#+end_src
