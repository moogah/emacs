* Lexical Binding

The lexical-binding mode line MUST be on line 1 of the tangled file, so this first block uses
=:comments no= to keep org structure comments from being inserted ahead of it.

#+begin_src emacs-lisp :comments no
;;; manifest.el --- The agent tool manifest -*- lexical-binding: t; -*-
#+end_src

* The agent manifest

=jf/agent-api= will live here: at call time it returns a JSON array with one object per
preset-allowlisted tool name that =jf/agent--registry-lookup= finds, giving its name, category,
tier, description and arguments (design.md seam/manifest).

Until a later task of the change fills it, this file is a stub: it loads cleanly and requires nothing.

* Module Initialization

#+begin_src emacs-lisp
(provide 'emacs-agent-manifest)
;;; manifest.el ends here
#+end_src
