#+property: header-args:emacs-lisp :tangle git-worktrees.el

* Overview

This module makes git worktrees the *second* real consumer of the
workspace integration registry (=config/workspaces/integrations.el=),
after gptel-sessions (=config/gptel/sessions/workspace-integration.org=).
It is the consumer side of the boundary: it MAY name magit symbols and
calls into =workspace-register-integration=, but the workspaces core
never depends on magit or git (directionality contract,
=register/boundary/gptel-sessions-workspace-consult=).

The module hard-depends on magit for the actual worktree operations
(implemented in dependent tasks), but registration happens *only* under
=with-eval-after-load 'magit= — so the module stays honestly droppable:
absent magit means no integration, not an error
(=register/invariant/workspaces-transient-deferred-require=).  Magit is
never required at top level; that would be a load-order hazard against a
straight-overridden package.

** Repo-source seam

=jf/workspace--worktree-repo-candidates= is the "leverage where
valuable, without a hard dependency" seam (design.md D1, D2).  It has
exactly two sources, in order:

1. *Git-derived discovery* (primary): the checkouts already in view
   (the current workspace's worktrees, other registered workspaces'
   worktrees, and =jf/emacs-dir=), expanded via git to every checkout of
   their repositories.
2. =(magit-list-repos)=, when magit is loaded.  It is driven by
   =magit-repository-directories=, which is unset in this config, so
   *today the candidate list is git-derived only*.

=projectile-known-projects= and =project-known-project-roots= are
deliberately *not* consulted, even when projectile or project.el is
loaded and populated.  The user judged them unreliable (2026-09-25).
They report only repositories someone registered with them, so their
lists differ between machines for reasons unrelated to what is actually
cloned, and they may name another workspace's checkout.

*Every* candidate, from either source, is classified, and only
=canonical= checkouts (a repository's main worktree) are offered.  A
source for a *new* worktree must never be another workspace's worktree
or clone of a repository: chaining checkouts makes the ownership of a
branch ambiguous, and purging the owning workspace would delete the
new worktree's repository.  This is the same safety rule the bookmark
resolver applies.

Discovery and classification reuse the =portable-bookmarks= helpers
(=workspace-bookmark--checkouts-in-view=, =--checkouts-of=,
=--classify=) through =fboundp= guards checked at *call* time.  This
module never =require=s portable-bookmarks, because a magit-dependent
module must not depend on a bookmark module.  When portable-bookmarks is
not loaded, the git-derived source contributes nothing and magit's
candidates pass through unclassified.  When a helper is loaded but
signals, one warning is shown and that step contributes nothing (a
failed classification offers nothing rather than something unchecked).

The merged list is de-duped on each candidate's *truename* directory
(so a symlinked spelling of a repository git reports resolved is listed
once, in the first spelling seen) and filtered to real git repositories.
The =read-directory-name= floor and free-form entry in
=jf/workspace--worktree-read-repo= are unchanged, so a repository that
no source suggests is still reachable by typing its path.  That is why
no source is a hard dependency.

* Repo-candidate Helper

Collects repository roots from git-derived discovery and from magit's
repository list (when magit is loaded), de-dupes them, keeps only actual
git repositories, and then keeps only =canonical= checkouts.  Pure and
list-returning: it never prompts, so it is directly unit-testable.

The portable-bookmarks calls are guarded with =fboundp= at call time.
git-worktrees loads *before* portable-bookmarks in =workspaces.org=, and
must keep working when that module is never loaded at all.  No
=declare-function= is used: the guard, not the byte-compiler, is the
contract.

A helper that is *present but broken* must not abort the add-worktree
command before it reaches its =read-directory-name= floor, because the
helpers are another module's internals.  Each call is therefore wrapped
in an error barrier that shows one warning (reporting the failure, not
hiding it) and contributes nothing.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-warn-discovery (what err)
  "Display one warning that WHAT failed with ERR."
  (display-warning
   'workspace-git-worktrees
   (format "%s unavailable (portable-bookmarks discovery failed): %s"
           what (error-message-string err))
   :warning))
#+end_src

De-duplication is keyed on each candidate's *truename*.  Git reports
resolved paths (on macOS a temp repository is =/private/var/...=), while
another source may have recorded the same repository through a symlinked
prefix (=/var/...=).  The first occurrence's spelling is the one
offered, so the git-derived spelling wins.  Remote (TRAMP) entries are
keyed on their expanded name and never resolved, so building the list
touches no network.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-dedupe-dirs (dirs)
  "Return DIRS as absolute directory names, without duplicates.
Each entry is expanded and given a trailing slash.  Two entries are
duplicates when they name the same directory: local entries are
compared by `file-truename', so spellings through a symlinked prefix
collapse; remote entries are compared by their expanded name.  The
first occurrence's spelling is kept, in order.  nil entries are
dropped."
  (let ((seen (make-hash-table :test #'equal))
        (out '()))
    (dolist (d dirs)
      (when d
        (let* ((dir (file-name-as-directory (expand-file-name d)))
               (key (if (file-remote-p dir)
                        dir
                      (condition-case nil
                          (file-name-as-directory (file-truename dir))
                        (error dir)))))
          (unless (gethash key seen)
            (puthash key t seen)
            (push dir out)))))
    (nreverse out)))
#+end_src

#+begin_src emacs-lisp
(defun jf/workspace--worktree-git-derived-candidates ()
  "Return every checkout of the repositories in view, or nil.
Asks `workspace-bookmark--checkouts-in-view' for the checkouts already
in view and expands each to every checkout of its repository with
`workspace-bookmark--checkouts-of'.  The result is NOT yet classified;
`jf/workspace--worktree-canonical-only' does that for every source.
Those helpers belong to the portable-bookmarks module, which this module
does not require.  When any of them, or `workspace-bookmark--classify',
is unbound, the result is nil.  Never signals: if a helper signals, one
warning naming the error is displayed and the result is nil."
  (when (and (fboundp 'workspace-bookmark--checkouts-in-view)
             (fboundp 'workspace-bookmark--checkouts-of)
             (fboundp 'workspace-bookmark--classify))
    (condition-case err
        (delete-dups
         (seq-mapcat (lambda (checkout)
                       (funcall 'workspace-bookmark--checkouts-of checkout))
                     (funcall 'workspace-bookmark--checkouts-in-view)))
      (error
       (jf/workspace--worktree-warn-discovery "Git-derived repo candidates" err)
       nil))))
#+end_src

#+begin_src emacs-lisp
(defun jf/workspace--worktree-canonical-only (dirs)
  "Return the members of DIRS classified `canonical'.
Classification is by `workspace-bookmark--classify'.  When the classifier is unbound (portable-bookmarks not loaded), DIRS is
returned unchanged.  Never signals: if the classifier signals, one
warning naming the error is displayed and the result is nil, so nothing
unchecked is offered and the caller's floor prompt still works."
  (if (not (fboundp 'workspace-bookmark--classify))
      dirs
    (condition-case err
        (seq-filter
         (lambda (dir)
           (eq 'canonical (funcall 'workspace-bookmark--classify dir)))
         dirs)
      (error
       (jf/workspace--worktree-warn-discovery "Repo candidate classification" err)
       nil))))
#+end_src

#+begin_src emacs-lisp
(defun jf/workspace--worktree-repo-candidates ()
  "Return the canonical git-repo roots offered as worktree sources.
The sources, in order, are the git-derived candidates
\(`jf/workspace--worktree-git-derived-candidates') and then
`(magit-list-repos)' when magit is loaded.  Projectile and project.el
lists are deliberately not consulted.  Paths are de-duped by
`jf/workspace--worktree-dedupe-dirs' (same directory by truename, first
spelling kept) and filtered to actual git repositories (via
`locate-dominating-file' on \".git\", or `magit-toplevel' when magit is
loaded).  Every survivor is then classified by
`jf/workspace--worktree-canonical-only'.  Returns the list; does not
prompt."
  (let ((raw (copy-sequence (jf/workspace--worktree-git-derived-candidates))))
    (when (and (featurep 'magit) (fboundp 'magit-list-repos))
      (setq raw (append raw (magit-list-repos))))
    (jf/workspace--worktree-canonical-only
     (seq-filter #'jf/workspace--worktree-git-repo-p
                 (jf/workspace--worktree-dedupe-dirs raw)))))
#+end_src

A small predicate isolates the "is this an actual git repo?" test so it
can be reasoned about (and spied) on its own.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-git-repo-p (dir)
  "Return non-nil when DIR is the root (or inside) a git repository.
Prefers `magit-toplevel' when magit is loaded; otherwise falls back to
`locate-dominating-file' looking for a \".git\" entry."
  (or (and (featurep 'magit) (fboundp 'magit-toplevel)
           (magit-toplevel dir))
      (locate-dominating-file dir ".git")))
#+end_src

* Repo-read Helper

The ONLY place that prompts.  Offers the candidate list via
=completing-read= but always allows a free-form entry; if the user
declines the candidates entirely, a =read-directory-name= floor still
reaches any repo on disk.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-read-repo ()
  "Prompt for a source git repository, returning an absolute directory.
Offers `jf/workspace--worktree-repo-candidates' via `completing-read'
with `require-match' nil, so a free-form path is always accepted.  If
the entered path is not an existing directory, falls back to a
`read-directory-name' floor — guaranteeing a repo present in no project
source is still reachable.  Returns the chosen directory, expanded."
  (let* ((cands (jf/workspace--worktree-repo-candidates))
         (choice (completing-read "Source git repo: " cands nil nil)))
    (if (and choice (file-directory-p (expand-file-name choice)))
        (expand-file-name choice)
      (expand-file-name (read-directory-name "Source git repo: ")))))
#+end_src

* Branch-name Sanitizer

Turns a workspace name into a valid git ref fragment.  Used only to
seed the editable default for the branch prompt — the user always sees
the sanitized result and may edit it further.  Replaces whitespace and
the characters git forbids in ref components (per =git check-ref-format=,
plus the at-brace sequence) with a hyphen, collapses runs, and trims
leading/trailing hyphens.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-sanitize-branch (name)
  "Return NAME sanitized into a valid git ref-component default.
Replaces whitespace and git-illegal ref characters (space, tilde,
caret, colon, question-mark, asterisk, open-bracket, backslash,
control chars, and the at-brace sequence) with \"-\", collapses
repeated \"-\", and trims leading/trailing \"-\".  Intended to seed
an editable prompt default, not to be authoritative."
  (let* ((s (or name ""))
         (s (replace-regexp-in-string "@{" "-" s))
         (s (replace-regexp-in-string "[[:space:][:cntrl:]~^:?*\\[\\\\]" "-" s))
         (s (replace-regexp-in-string "-+" "-" s))
         (s (replace-regexp-in-string "\\`-+\\|-+\\'" "" s)))
    s))
#+end_src

* Menu Handler

On-demand =:menu= command.  Operates SOLELY on the anchor PAYLOAD (the
=:menu= calling convention) — never on the current tab.  Reads the
=:name= (workspace name → shared feature branch) and =:home=
(container dir → worktree parent) from the payload
(=register/shape/workspace-integration-anchor-payload=).

It prompts for the source repo, detects that repo's main branch, and
creates a new worktree off main inside =:home=, named for the source
repo's basename.  Returns one of the outcome vocabulary values
=ok= | =(failed . REASON)=
(=register/vocabulary/workspace-integration-outcome=).

Every =magit-*= call is wrapped in an explicit
=(let ((default-directory repo)) ...)= so the operation runs against
the chosen repo and not whatever happens to be current
(design D1 / Risks — the
=register/invariant/git-worktree-default-directory-binding= contract).

#+begin_src emacs-lisp
(defun jf/workspace--add-worktree (payload)
  "Create a git worktree off main for the workspace described by PAYLOAD.
PAYLOAD is the workspace-integration anchor plist; this reads `:name'
\(the workspace name, used as the default shared feature branch) and
`:home' (the workspace container directory, used as the worktree
parent).  Operates solely on PAYLOAD, never on the current tab.

Prompts for a source repo (`jf/workspace--worktree-read-repo'),
detects its main branch (`magit-main-branch' with `default-directory'
bound to the repo), and prompts for a branch name defaulting to the
sanitized workspace name.  The worktree directory is a child of
`:home' named for the source repo's basename.

If the target directory already exists, returns
\(failed . REASON) and makes NO magit call — never overwriting.
Otherwise creates the worktree on a NEW branch off main via
`magit-worktree-branch' (again with `default-directory' bound to the
repo).  Returns `ok' on success, or (failed . REASON) on any git
error."
  (let* ((repo (jf/workspace--worktree-read-repo))
         (main (let ((default-directory repo))
                 (magit-main-branch)))
         (default-branch (jf/workspace--worktree-sanitize-branch
                          (plist-get payload :name)))
         (branch (read-string "Worktree branch: " default-branch))
         (dir (expand-file-name
               (file-name-nondirectory (directory-file-name repo))
               (plist-get payload :home))))
    (if (file-exists-p dir)
        (cons 'failed (format "worktree dir already exists: %s" dir))
      (condition-case err
          (progn
            (let ((default-directory repo))
              (magit-worktree-branch dir branch main))
            'ok)
        (error (cons 'failed (error-message-string err)))))))
#+end_src

* On-purge Teardown Handler

The =:on-purge= handler.  It runs BEFORE =workspace-purge= deletes
=:home=, so the linked worktrees still exist on disk and can be
removed cleanly from their source repos.

A child of =:home= is treated as a linked git worktree when its =.git=
entry is a FILE (not a directory) — a linked worktree's =.git= is a
gitfile pointing into the source repo's gitdir, whereas a normal repo
root has a =.git= directory.  From inside such a child (with
=default-directory= bound there), =magit-list-worktrees= enumerates the
source repo's worktrees; its FIRST element is the source repo's primary
worktree, which is where the removal and branch-deletion magit calls
must run.

Why teardown removes the worktree from its SOURCE repo rather than
letting the purge raw-delete the directory (design.md D3, D5): the
worktree registry lives in the source repo, OUTSIDE =:home=.  A raw
delete would leave each source repo holding a stale/prunable worktree
entry pointing at a deleted dir.  Branch deletion is GUARDED by
=magit-branch-merged-p= (magit's own branch-UI safety check) so
possibly-unfinished work is never destroyed; an unmerged branch is
kept and never force-deleted.  A worktree that magit refuses to remove
(e.g. a dirty tree) is reported, not forced, and never aborts the
purge — the continue-past-one-failure shape mirrors
=workspace--run-one-integration=.

INVARIANT: every =magit-*= call is wrapped in an explicit
=(let ((default-directory repo-or-worktree)) ...)= so it operates on the
intended repo, never on whatever happens to be current
(=register/invariant/git-worktree-default-directory-binding=).

A small helper resolves the child worktrees under =:home= into the data
the handler needs.  It returns, for each linked worktree child, a plist
=(:dir :branch :source)= where =:source= is the source repo's primary
worktree.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-children (home)
  "Return a list of linked-worktree descriptors under HOME.
Scans the immediate child directories of HOME and keeps those whose
`.git' entry is a FILE (a linked worktree's gitfile), not a directory.
For each, binds `default-directory' into the child and calls
`magit-list-worktrees' to resolve the source repo's worktree list,
whose FIRST element is the source repo's primary worktree.  Returns a
list of plists (:dir CHILD :branch BRANCH :source SOURCE-REPO), where
BRANCH is the child worktree's branch and SOURCE-REPO is the source
repo's primary worktree directory.  Children that do not resolve are
skipped."
  (let ((acc '()))
    (when (and home (file-directory-p home))
      (dolist (child (directory-files home t directory-files-no-dot-files-regexp))
        (when (and (file-directory-p child)
                   (file-regular-p (expand-file-name ".git" child)))
          (let* ((default-directory (file-name-as-directory child))
                 (worktrees (magit-list-worktrees))
                 (source (car (car worktrees)))
                 (self (seq-find
                        (lambda (wt)
                          (file-equal-p (car wt) child))
                        worktrees))
                 (branch (and self (nth 2 self))))
            (when source
              (push (list :dir child :branch branch :source source) acc))))))
    (nreverse acc)))
#+end_src

The handler itself iterates the descriptors, removing each worktree
from its source repo and offering guarded branch deletion, accumulating
any failures into a single reason while continuing past them.

#+begin_src emacs-lisp
(defun jf/workspace--worktree-on-purge (payload)
  "Tear down git worktrees living under PAYLOAD's `:home' before purge.
PAYLOAD is the workspace-integration anchor plist; this reads `:home'
\(the container whose child worktrees are removed)
\(register/shape/workspace-integration-anchor-payload).  Runs BEFORE
the purge deletes `:home', so the worktrees still exist on disk.

Enumerates the linked worktrees under `:home' via
`jf/workspace--worktree-children'.  For each, binds `default-directory'
into that worktree's SOURCE repo and calls `magit-worktree-delete' to
remove it, wrapped in `condition-case'.  If a removal signals (e.g. a
dirty tree magit refuses), its path is accumulated into a failure
reason and the remaining worktrees are still processed — never aborts.

After a successful removal, offers GUARDED branch deletion: only when
`magit-branch-merged-p' reports the branch merged into the source
repo's main branch is `magit-branch-delete' called, WITHOUT force.
Unmerged branches are kept and never force-deleted.

Returns `skipped' when there are NO worktrees under `:home', `ok' when
every worktree was removed cleanly, or (failed . REASON) naming the
worktree(s) that could not be removed
\(register/vocabulary/workspace-integration-outcome)."
  (let ((children (jf/workspace--worktree-children (plist-get payload :home))))
    (if (null children)
        'skipped
      (let ((failures '()))
        (dolist (wt children)
          (let ((dir (plist-get wt :dir))
                (branch (plist-get wt :branch))
                (source (plist-get wt :source)))
            (condition-case err
                (progn
                  (let ((default-directory source))
                    (magit-worktree-delete dir))
                  (when branch
                    (let* ((default-directory source)
                           (main (magit-main-branch)))
                      (when (and main
                                 (magit-branch-merged-p branch main))
                        (magit-branch-delete (list branch))))))
              (error (push (format "%s (%s)" dir (error-message-string err))
                           failures)))))
        (if failures
            (cons 'failed
                  (concat "could not remove worktree(s): "
                          (mapconcat #'identity (nreverse failures) "; ")))
          'ok)))))
#+end_src

* Registration

Gated so ABSENT MAGIT = NO integration (not an error).  Registration is
wrapped in =with-eval-after-load 'workspaces= (load-order-independent
attachment to the registry) and =with-eval-after-load 'magit= (the
deferred-require invariant for the straight-overridden magit package).

The =:menu= and =:on-purge= handler symbols are implemented in dependent
tasks; the forward =#'symbol= references are fine because registration
only *stores* the symbol — it never calls it here.

#+begin_src emacs-lisp
(with-eval-after-load 'workspaces
  (with-eval-after-load 'magit
    (workspace-register-integration 'git-worktree
      :label "git worktree"
      :menu (cons "w" #'jf/workspace--add-worktree)
      :on-purge #'jf/workspace--worktree-on-purge)))
#+end_src
