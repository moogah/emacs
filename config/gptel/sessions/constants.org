* Introduction

Centralized constants and configuration for gptel persistent sessions.
This module defines magic strings, directory paths, and configuration variables used across all session modules.

* File Name Constants

Standard file names used within session directories.

The agents directory is the one /hidden/ name in the tree
(=.agents/=). Branch creation byte-copies agent directories wholesale,
so copied agent transcripts still carry the parent's org IDs; a hidden
name keeps them out of any indexer that skips dot-directories, without
this package naming an indexer. The name is spelled exactly ONCE — in
=jf/gptel-session--agents-dir= below — and every path that reaches it
is composed through =jf/gptel--agents-dir-path= (filesystem.org).
There is no compatibility shim for the former =agents/= name: the
migration command renames existing directories.

#+begin_src emacs-lisp
(defconst jf/gptel-session--context-file "session.org"
  "File name for main conversation context.
Uses org-mode format with `gptel-chat-mode' block delimiters.")

(defconst jf/gptel-session--tools-log-file "tools.org"
  "File name for tool call log.
Uses org-mode format for better structure and linking.")

(defconst jf/gptel-session--system-prompts-file "system-prompts.org"
  "File name for system prompt change log.
Uses org-mode format for better structure.")

(defconst jf/gptel-session--agents-dir ".agents"
  "Directory name for agent sessions within a parent branch directory.
Hidden (dot-prefixed) so an indexer that skips hidden directories
excludes agent transcripts, which are byte copies carrying the parent's
org IDs.  This constant is the only place the name is spelled; compose
paths through `jf/gptel--agents-dir-path', never from a literal.  No
compatibility shim exists for the former \"agents\" name.")

#+end_src

* Buffer-Local Session Variables

Variables that track session state in gptel buffers.

#+begin_src emacs-lisp
(defvar-local jf/gptel--session-id nil
  "Unique identifier for the current gptel session.
Format: <slug>-<timestamp>, e.g., 'react-refactoring-20260120153042'.")

(defvar-local jf/gptel--session-dir nil
  "Absolute path to the directory for the current session.
All session files (context, metadata, tools log, etc.) are stored here.")

(defvar-local jf/gptel--branch-name nil
  "Name of the current branch within the session.
Typically 'main' for the primary branch, or timestamped names for alternate branches.")

(defvar-local jf/gptel--branch-dir nil
  "Absolute path to the current branch directory.
This is where session.org (with the embedded :PROPERTIES: scope drawer) is located.
For regular sessions: <session-dir>/branches/<branch-name>/
For agents: <session-dir>/ (agents don't use branch subdirectories).")

(defvar-local jf/gptel--parent-session-id nil
  "Session ID of parent session (for agents only).
Nil for top-level sessions.")
#+end_src
